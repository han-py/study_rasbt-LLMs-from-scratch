    if not os.path.exists(file_path):

### 🌟 代码清单 7-2：实现提示词格式函数 (`format_input`)
AI 无法像人一样“凭借感悟”区分哪里是题干，哪里是补充材料。所以我们要给它定制一个死板但极其清晰的“模板剧本”。
```python
def format_input(entry):
    # 强制加上前置指令引导语，给模型立人设
    instruction_text = (
        f"Below is an instruction that describes a task. "
        f"Write a response that appropriately completes the request."
        f"\n\n### Instruction:\n{entry['instruction']}"
    )
    # 如果题目自带前置文本（比如翻译题的待翻译部分），也拼上去
    input_text = f"\n\n### Input:\n{entry['input']}" if entry["input"] else ""
    return instruction_text + input_text
# 💡 这时，一段杂乱的数据就被拼成了带有 ### Instruction 和 ### Input 的标准公文。
```

## 🧩 阶段二：把人类语言转化为数学矩阵 (代码清单 7-4 至 7-6)
这一阶段是数据处理的**灵魂地带**！由于 GPU 算力极其硬核，但它只认识规规矩矩的“长方形数字矩阵”，我们的终极目标是把长短不一的句子转化为矩阵。
### 🌟 代码清单 7-4：实现指令数据集类 (`InstructionDataset`)
借助 OpenAI 提供的字典本（ 分词器 Tokenizer），我们将汉字/英文字母映射为诸如 `[115, 654, 888]` 的数字密码。
```python
import tiktoken
tokenizer = tiktoken.get_encoding("gpt2") 
class InstructionDataset(Dataset):
    def __init__(self, data, tokenizer):
        self.encoded_texts = []
        for entry in data:
            # 拼接前面的题目和后面的标准答案（以 ### Response: 分界）
            full_text = format_input(entry) + f"\n\n### Response:\n{entry['output']}"
            # 将整段字符串打碎为数字密码并存起来
            self.encoded_texts.append(tokenizer.encode(full_text))
    def __getitem__(self, index): return self.encoded_texts[index]
    def __len__(self): return len(self.data)
```
### 🌟 代码清单 7-5：自定义批聚合函数 (`custom_collate_fn`)
这是让句子能够放进 GPU 的**核心机密**！包含了“截长补短”和“免死金牌”两大绝招。
```python
def custom_collate_fn(batch, pad_token_id=50256, ignore_index=-100, allowed_max_length=None, device="cpu"):
    # 找到本次抽查的卷子里最长的那份（比方说最长是100个词元）
    batch_max_length = max(len(item)+1 for item in batch)
    inputs_lst, targets_lst = [], []
    for item in batch:
        new_item = item.copy() + [pad_token_id] # 结尾加上终止符
        # ⚡ 截长补短：如果这个卷子不够长，就在结尾狂垫 50256 (空白符)，强行逼齐100个长度！
        padded = new_item + [pad_token_id] * (batch_max_length - len(new_item))
        # ⚡ 错位接龙：大模型是根据前文猜下文。
        # 所以 inputs 切掉末尾，targets 切掉开头。输入“天 空 是”，目标就是“空 是 蓝”。
        inputs = torch.tensor(padded[:-1])
        targets = torch.tensor(padded[1:])
        # 🎯 免死金牌机制：
        # 不能让大模型浪费脑细胞去学习怎么输出无聊的空白符 50256！
        # 我们寻找出 targets 填补的 50256，把它们篡改为 PyTorch 的法外狂徒数字：-100。
        # PyTorch 的错误率评价器只要看到 -100，直接无视，不加分也不扣分！
        mask = targets == pad_token_id
        indices = torch.nonzero(mask).squeeze()
        if indices.numel() > 1:
            targets[indices[1:]] = ignore_index
        inputs_lst.append(inputs)
        targets_lst.append(targets)
    # 堆叠成矩形推入显卡
    return torch.stack(inputs_lst).to(device), torch.stack(targets_lst).to(device)
```

## ⚔️ 阶段四：魔鬼微调训练营 (代码清单 7-8 与核心算分引擎)
这是让大语言模型“学会职场规矩”的动力室，完整复现了经典的**深度学习反向传播大循环**。
### 🌟 核心铺垫：评分器 (`calc_loss_batch`) 与打字机 (`generate`)
* `Cross Entropy` 交叉熵损失函数充当了**计分员**。模型不仅要答对，还要信心满满地答对，错得越离谱，分数(Loss)越高。
* `generate` 引擎在推理阶段生效，用一个循环迫使模型**每一个轮回憋出一个字**，内部还包含了极其天才的：
  * **Top-K 锁**：一剪刀剪掉那些末流选项（填入负无穷大），防止模型说天书乱语。
  * **Temperature 温度参数**：温度为 0 它是只挑最高得分字的无情直男；温度大于 0 它是敢于掷骰子挑选低频字作诗的醉酒诗人！
### 🌟 代码清单 7-8：对预训练模型进行指令微调

**🔍 什么是 `train_model_simple` 隐去的底层运作？**
1. **`optimizer.zero_grad()`**：清空昨天的粉笔灰。
2. **`loss = calc_loss_batch(...)`**：自己做一题，和标准答案比对看有多蠢。
3. **`loss.backward()`**（反向传播）：算出这么蠢究竟是被上亿参数里的哪一波旋钮牵连的，生成一个“梯度”报告。
4. **`optimizer.step()`**：优化器拿着锤子，照着报告把那几个旋钮往正确方向拧动千分之一圈！周而复始。

def generate_model_scores(json_data, json_key, model="llama3"):
    scores = []
    for entry in tqdm(json_data, desc="Scoring entries"):
        # 极致的神级打分 Prompt 话术：“左边是小AI答的破题，右边是真理教科书，请你在一百分制下给出打分整数！”
        prompt = (
            f"Given the input `{format_input(entry)}` "
            f"and correct output `{entry['output']}`, "
            f"score the model response `{entry[json_key]}`"
            f" on a scale from 0 to 100, where 100 is the best score. "
            f"Respond with the integer number only." 
        )
        score = query_model(prompt, model=model)
        try: scores.append(int(score))
        except ValueError: continue
    return scores
